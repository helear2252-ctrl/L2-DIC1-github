# ✨ Premium Live Clock & Timezone Dashboard

A highly customized, premium-tier, and fully interactive personal dashboard built for **JUN WEI**. Designed with modern glassmorphism aesthetics, fluid ambient backgrounds, 3D perspective shifts, and responsive layouts.

🚀 **Live Site:** [https://helear2252-ctrl.github.io/L2-DIC1-github/](https://helear2252-ctrl.github.io/L2-DIC1-github/)

🔗 **Live Demo:** [https://github.com/helear2252-ctrl/L2-DIC1-github.git](https://github.com/helear2252-ctrl/L2-DIC1-github.git)

---

## 🌟 Key Features

* **🕰️ High-Fidelity Clock**: A real-time digital clock rendering hours, minutes, and seconds dynamically.
* **📈 Second-by-Second Progress Meter**: A sleek micro-interactive bar indicating the exact completion percentage of the current minute.
* **🌍 Automatic Timezone Detection**: Automatically displays the host system timezone with an integrated click-to-clipboard copier and elegant toast messages.
* **🔄 Format Toggler**: Seamlessly switch between standard **12-Hour (AM/PM)** and **24-Hour** time formats.
* **🎨 Ambient Customizer**: Instantly swap between 4 premium aesthetic theme presets:
  - **Electric Violet** (Deep cosmic glow)
  - **Cyberpunk Neon** (Fierce cyan & magenta)
  - **Aurora Green** (Calm ocean teal)
  - **Amber Horizon** (Warm sunset golds)
* **✨ Dynamic 3D Card Tilt**: The central dashboard card shifts in 3D perspective to track mouse cursor movement dynamically.
* **🌅 Time of Day Greetings**: Automatically changes greet labels (e.g. *Good Morning*, *Good Afternoon*, *Good Evening*) depending on your active hour of the day.

---

## 🛠️ Built With

* **HTML5**: Structured semantically for high performance and optimal SEO indexability.
* **Vanilla CSS3**: Engineered with modern CSS variables, responsive viewport grid adjustments, `@keyframes` drift coordinates, and glassmorphism styling (`backdrop-filter`). No bulky third-party libraries needed.
* **Vanilla JavaScript**: Powered by high-efficiency `setInterval` rendering cycles updating at 100ms intervals for absolute clock precision.

## 💻 How to Run Locally

Since this project is completely self-contained within a single index file, running it locally is incredibly easy:

1. Clone this repository:
   ```bash
   git clone https://github.com/helear2252-ctrl/L2-DIC1-github.git
   ```
2. Navigate into the directory:
   ```bash
   cd L2-DIC1-github
   ```
3. Open `index.html` in your favorite web browser (Chrome, Safari, Firefox, Edge, etc.) or serve it using any simple local server.

---

## 🌐 Deploy to GitHub Pages

Deploying your own branch is fully automated:

1. Head to your repository settings on GitHub: `https://github.com/helear2252-ctrl/L2-DIC1-github/settings`
2. Scroll to the **Pages** menu on the left.
3. Under **Build and deployment > Branch**, set your build source to **`main`** and click **Save**.
4. Your site will automatically go live within seconds!
